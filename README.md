Fungi explorer is a website for people intereseted in mushrooms and nature. Users can explore different mushroom species, search for spesific species, sort them alphabetically, and learn about their appearance, habitats, characteristics and potential toxicity.

How to install and run the project

1. Clone the repository
    git clone [repository-url]

2. Navigate to the project folder
    cd fungi-explorer

3. Install npm
    npm install

4. Start the server
    npm run dev

5. Open http://localhost:3000 in your browser


API and data source

The project uses Mushroom Tracker Data, a dataset hosted on GitHub:
https://github.com/jrowinski3d/mushroom-tracker-data-cdn

Known bugs and limitations

Loading the Overview page takes a few seconds because the website needs to fetch the data for all mushroom species.
